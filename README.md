This is the repository for the paper *Query Type and Ranking Methods Influence the Stance Distribution of Search Results on Controversial Topics*.

This directory contains the following CSV files:

- `all_queries.csv`: all generated queries
- `all_stance_distribution_at3.csv`: stance distributions at 3 for all queries
- `all_stance_distribution_at5.csv`: stance distributions at 5 for all queries
- `all_stance_distribution_at10.csv`: stance distributions at 10 for all queries
